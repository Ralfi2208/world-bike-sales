# World Bike Sales Analytics - Power BI Dashboard

## 📊 Project Overview
This interactive Power BI dashboard provides an end-to-end analysis of global bike sales performance, product profitability, customer demographics, and regional market insights.

## 🔑 Key Metrics (KPIs)
* **Total Sales:** $85.3M
* **Total Profit:** $32.2M
* **Profit Margin:** 37.79%
* **Total Orders:** 113K
* **Total Cost:** $53.05M

## 🛠️ Tools & Technologies
* **Power BI Desktop:** Star schema data modeling, DAX measures, interactive tooltips, and dynamic visuals.
* **Power Query:** Data cleaning, type transformations, and schema optimization.
* **Source Dataset:** Kaggle (Bike Store Sales in Europe / Global).

## 💡 Key Insights
* Analyze top-performing regions and order volumes across multiple countries.
* Evaluate sales performance across different customer age groups and gender segments.
